# 运行视频录制指南

建议视频时长为 4 到 6 分钟。录制前关闭包含个人信息的窗口，只使用无隐私演示图片。

## 录制前检查

1. 启动 Ollama，并确认 `ollama list` 中有 `qwen3-vl:4b`。
2. 双击项目根目录的 `start_app.bat`。
3. 确认浏览器打开 `http://127.0.0.1:8501`。
4. 准备无隐私演示图片。
5. 关闭通知弹窗，隐藏无关窗口和文件路径。

## 分镜与讲解稿

### 00:00 - 00:30 项目介绍

展示网页标题并讲解：

> 这是我的桌面物品清点项目。项目使用同一张图片，对比 YOLO 加 MobileSAM 的传统视觉方案，以及本地 Qwen3-VL 多模态大模型方案。所有图片都在本机处理。

### 00:30 - 01:00 输入与人工正确答案

选择无隐私演示图片，暂时不要点击运行。讲解：

> 图片中有一个瓶子、一个蓝牙耳机盒、一个鼠标和一支笔。这份人工清单用于判断模型的误检和漏检。

### 01:00 - 01:30 运行项目

点击“运行两种方案”，展示三个处理阶段。讲解：

> 程序先由 YOLO 检测类别和边界框，再用这些框提示 MobileSAM 生成分割掩膜，最后由本机 Qwen3-VL 生成结构化物品清单。

### 01:30 - 02:30 传统视觉方案

展示 YOLO 和 MobileSAM 图片及表格。讲解：

> YOLO 正确识别了瓶子和鼠标，但把蓝牙耳机识别成第二个鼠标，把笔识别成棒球棒，还把桌面背景识别为餐桌。MobileSAM 成功生成了对应轮廓，但它继承 YOLO 的类别，不能纠正误分类。

### 02:30 - 03:30 视觉大模型方案

展示 Qwen3-VL 表格。讲解：

> Qwen3-VL 正确输出了饮料瓶、耳机盒、鼠标和笔，每类数量都是一个，并给出了文字判断依据。它对开放类别的理解更强，但没有直接输出边界框和像素掩膜。

### 03:30 - 04:20 方案比较

讲解：

> 传统方案适合类别固定、需要定位、计数和分割的任务；视觉大模型适合开放类别识别、描述和问答。两种方案能力互补，实际项目可以组合使用。

### 04:20 - 05:00 隐私与总结

展开页面中的“隐私与运行方式”。讲解：

> 原始图片和结果目录都被 Git 忽略。Qwen3-VL 通过 Ollama 在本机运行，程序只连接 127.0.0.1。整个开发过程使用 Git 持续提交，保留了真实历史。

## 录制完成后检查

- 视频画面和声音清晰。
- 视频中没有私人图片、通知、账号、二维码或访问令牌。
- 能看到输入、运行过程、主要结果和方案比较。
- 视频文件能正常播放，再按考核要求提交。
