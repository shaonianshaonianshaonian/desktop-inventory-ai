# 学习与开发记录

## 第 1 阶段：项目准备

- 目标：建立项目结构、独立 Python 环境和 Git 仓库。
- 已了解：本项目需要让传统视觉模型和视觉大模型处理同一组图片，再比较结果。
- 待完成：创建 Python 3.11 环境并验证运行。

## 第 2 阶段：OpenCV 图片处理

- `cv2.imread`：从文件读取图片。
- `image.shape`：获得图片高度、宽度和通道数。
- `cv2.resize`：缩放图片。
- `cv2.putText`：在图片上绘制文字。
- `cv2.imwrite`：把处理结果保存为文件。
- 验证环境：Python 3.12.14、OpenCV 4.14.0、NumPy 2.5.4。
- 验证结果：成功读取 4080 x 3060 的桌面照片，并等比例缩放为 960 x 720。
- 结论：图片读取、缩放、文字标注和保存功能均正常。

## 第 3 阶段：YOLO 目标检测

- 类别（class）：模型认为物体属于哪一种类型。
- 置信度（confidence）：模型对该判断的把握程度，范围通常为 0 到 1。
- 边界框（bounding box）：包围物体的矩形，用左上角和右下角坐标表示。
- 当前任务：安装 Ultralytics，使用 `yolo26n.pt` 检测同一张桌面照片。
- 验证环境：Ultralytics 8.4.191，预训练模型 `yolo26n.pt`。
- 检测结果：`mouse` 2 个、`laptop` 1 个、`keyboard` 1 个。
- 置信度范围：0.43 到 0.90；鼠标的置信度最高，键盘最低。
- 观察：同一台笔记本同时被识别为 `laptop`，键盘区域又被识别为 `keyboard`。
- 隐私要求：原图与结果图只保存在本机，不上传或加入 Git 提交。

## 第 4 阶段：结果评估与结构化输出

- 人工正确答案：笔记本电脑 1、鼠标 1、蓝牙耳机 1。
- 正确检测：笔记本电脑、鼠标。
- 漏检：蓝牙耳机。
- 误检：一个额外的 `mouse`，很可能来自蓝牙耳机。
- 局部额外检测：笔记本电脑上的键盘被单独识别为 `keyboard`。
- 检测程序增加 JSON 输出，为后续双方案自动对比做准备。

## 第 5 阶段：MobileSAM 提示式分割

- 检测框：只表示物体的大致矩形位置。
- 分割掩膜：逐像素表示哪些区域属于目标物体。
- 提示：SAM 需要点、框或已有掩膜来指定要分割的对象。
- 组合流程：YOLO 检测框 → MobileSAM 框提示 → 物体掩膜。
- 当前任务：用同一张本地照片验证组合程序，结果仍只保存在本机。
- 验证模型：`mobile_sam.pt`，模型权重约 38.8 MB。
- 输入提示：读取 YOLO 生成的 4 个边界框。
- 输出结果：成功生成 4 个分割掩膜。
- 掩膜像素面积：两个 `mouse` 分别为 371354、141322，`laptop` 为 5509386，`keyboard` 为 2034312。
- 结论：SAM 能根据框分出物体轮廓，但会继承 YOLO 的类别结果，不能自行纠正误分类。
