## 第 2 阶段：OpenCV 图片处理

- `cv2.imread`：从文件读取图片。
- `image.shape`：获得图片高度、宽度和通道数。
- `cv2.resize`：缩放图片。
- `cv2.putText`：在图片上绘制文字。
- `cv2.imwrite`：把处理结果保存为文件。
- 验证环境：Python 3.12.14、OpenCV 4.14.0、NumPy 2.5.4。
- 验证结果：成功读取 4080 x 3060 的桌面照片，并等比例缩放为 960 x 720。
- 结论：图片读取、缩放、文字标注和保存功能均正常。

## 第 3 阶段：YOLO 目标检测

- 类别（class）：模型认为物体属于哪一种类型。
- 置信度（confidence）：模型对该判断的把握程度，范围通常为 0 到 1。
- 边界框（bounding box）：包围物体的矩形，用左上角和右下角坐标表示。
- 当前任务：安装 Ultralytics，使用 `yolo26n.pt` 检测同一张桌面照片。
- 验证环境：Ultralytics 8.4.191，预训练模型 `yolo26n.pt`。
- 检测结果：`mouse` 2 个、`laptop` 1 个、`keyboard` 1 个。
- 置信度范围：0.43 到 0.90；鼠标的置信度最高，键盘最低。
- 观察：同一台笔记本同时被识别为 `laptop`，键盘区域又被识别为 `keyboard`。
