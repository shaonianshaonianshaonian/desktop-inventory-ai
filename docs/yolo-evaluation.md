## 最终演示图片：YOLO 检测结果

| 模型类别 | 检测数量 | 结果分析 |
|---|---:|---|
| `bottle` | 1 | 正确识别瓶子 |
| `mouse` | 2 | 一个正确；另一个很可能是把蓝牙耳机误认为鼠标 |
| `baseball bat` | 1 | 很可能是把笔误认为棒球棒 |
| `dining table` | 1 | 把桌面背景作为餐桌额外检出，不计入物品清单 |
| 蓝牙耳机 | 0 | 漏检；预训练模型没有对应的常用 COCO 类别 |
| 笔 | 0 | 漏检；普通笔不属于该预训练检测模型的常用类别 |

## 严格类别统计

- 正确检测：2 个（瓶子、鼠标）。
- 漏检：2 个（蓝牙耳机、笔）。
- 额外或错误类别：3 个（额外的鼠标、棒球棒、餐桌）。

## 初步结论

预训练 YOLO 能快速定位已知类别，并给出边界框和置信度；对于训练类别之外或外形相似的物品，容易出现漏检与误检。后续将使用视觉大模型处理同一输入，并比较其能否正确理解“蓝牙耳机”和“笔”这两个语义类别。
