# YOLO 基线评估

## 人工正确答案

| 物品 | 实际数量 |
|---|---:|
| 带键盘的笔记本电脑 | 1 |
| 鼠标 | 1 |
| 蓝牙耳机 | 1 |

## YOLO 检测结果

| 模型类别 | 检测数量 | 结果分析 |
|---|---:|---|
| `laptop` | 1 | 正确识别笔记本电脑 |
| `mouse` | 2 | 一个正确；另一个很可能是把蓝牙耳机误认为鼠标 |
| `keyboard` | 1 | 识别到笔记本的键盘区域，属于局部额外检测 |
| 蓝牙耳机 | 0 | 漏检；预训练模型没有对应的常用 COCO 类别 |

## 初步结论

预训练 YOLO 能快速、稳定地定位其已知类别，并给出边界框和置信度；对于训练类别之外或外形相似的物品，容易出现漏检与误检。后续将使用视觉大模型处理同一输入，并比较其能否正确理解“蓝牙耳机”这一语义类别。
