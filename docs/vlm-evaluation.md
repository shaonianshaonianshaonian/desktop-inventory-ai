# 本地视觉大模型评估

## 运行设置

- 模型：Qwen3-VL 4B
- 运行方式：Ollama 本地服务
- 接口：`http://127.0.0.1:11434/api/chat`
- 图片预处理：在内存中等比例缩放，最大边长 1600
- 输出格式：JSON Schema 约束的结构化物品清单

## 识别结果

| 人工正确答案 | Qwen3-VL 输出 | 数量 | 判断 |
|---|---|---:|---|
| 瓶子 | 饮料瓶 | 1 | 正确，上位类别一致 |
| 蓝牙耳机 | 耳机盒 | 1 | 正确，识别到图片中可见的耳机充电盒 |
| 鼠标 | 鼠标 | 1 | 正确 |
| 笔 | 笔 | 1 | 正确 |

四类主要物品及其数量全部与人工正确答案对应。

## 与 YOLO + MobileSAM 的阶段性比较

| 对比项 | YOLO + MobileSAM | Qwen3-VL 4B |
|---|---|---|
| 严格类别正确数 | 2 / 4 | 4 / 4 |
| 额外或错误类别 | 3 | 0 |
| 边界框 | 有 | 无 |
| 像素掩膜 | 有 | 无 |
| 类别范围 | 受预训练固定类别限制 | 能用自然语言理解更多类别 |
| 输出解释 | 类别、置信度、坐标 | 名称、数量、置信度等级、文字依据 |
| 图片处理位置 | 本机 | 本机 Ollama |

传统方案适合快速定位、计数和精细分割；视觉大模型更适合理解开放类别和生成可读清单。两种方案能力互补。
