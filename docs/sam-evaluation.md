# MobileSAM 分割评估

## 运行结果

YOLO 提供 4 个边界框，MobileSAM 对每个边界框生成一个分割掩膜：

| 继承的 YOLO 类别 | 掩膜像素面积 |
|---|---:|
| `mouse` | 371354 |
| `mouse` | 141322 |
| `laptop` | 5509386 |
| `keyboard` | 2034312 |

## 结果理解

边界框只描述物体的大致矩形范围，掩膜则逐像素描述物体区域。MobileSAM 成功把每个检测框转换为更精细的轮廓，可以用于抠图、面积估计和数据标注。

SAM 是提示式分割模型，不负责为物体命名。本项目的类别名称来自 YOLO，因此 YOLO 对蓝牙耳机的误分类会继续出现在分割结果中。这说明“检测与分割组合”能改善定位精度，但不能解决检测模型类别范围有限的问题。
